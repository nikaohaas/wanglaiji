# 往来记

一款简洁的安卓业务流程记录工具，适合记录代采购、垫付、销售、开票、客户回款和最终结算的完整过程。

## 主要功能

- 新建、修改和删除账目
- 单独维护客户与供货商名单
- 记录需求日期、业务内容、供货金额和销售金额
- 跟踪供货结算、销售结算、开票、客户回款、结算五个步骤
- 为五个步骤分别记录完成日期
- 按客户、供货商、业务内容和日期搜索
- 记录进货金额、销售金额、税费与其他支出，自动计算本单利润
- 首页查看年度、月度销售额与盈亏，以及各月销售趋势
- 数据仅保存在手机本地，无需联网

## 安装

请前往仓库的 **Releases** 页面下载最新 APK，在安卓手机上打开安装。

当前版本：**v1.2.1**

## 使用说明

新建账目时，仅“日期”和“客户名称”为必填项，其余内容可以稍后补充或修改。将某个流程步骤标记为“是”时，软件会自动填写当天日期，也可以手动调整。

利润按“销售金额 − 进货金额 − 税费 − 其他支出”计算。销售或进货金额未填写时，单笔利润显示“待补金额”；税费和其他支出未填写时按 0 计算。首页看板按账目的需求日期归属年份和月份，未填金额的账目会单独提示。

删除账目时，需要在确认弹窗中输入“确认”后才能删除。

> 提醒：目前数据保存在应用本机。卸载应用或清除应用数据前，请确认不再需要其中的记录。
