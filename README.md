# 往来记

一款简洁的安卓业务流程记录工具，适合记录代采购、垫付、销售、开票、客户回款和最终结算的完整过程。

## 主要功能

- 新建、修改和删除账目
- 单独维护客户与供货商名单
- 记录需求日期、业务内容、供货金额和销售金额
- 跟踪供货结算、销售结算、开票、客户回款、结算五个步骤
- 为五个步骤分别记录完成日期
- 按客户、供货商、业务内容和日期搜索
- 数据仅保存在手机本地，无需联网

## 安装

请前往仓库的 **Releases** 页面下载最新 APK，在安卓手机上打开安装。

当前版本：**v1.1.0**

## 使用说明

新建账目时，仅“日期”和“客户名称”为必填项，其余内容可以稍后补充或修改。将某个流程步骤标记为“是”时，软件会自动填写当天日期，也可以手动调整。

> 提醒：目前数据保存在应用本机。卸载应用或清除应用数据前，请确认不再需要其中的记录。

## 开发环境

- Android 6.0 及以上
- Android SDK 34
- 原生 Android WebView
